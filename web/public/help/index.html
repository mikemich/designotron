Getting started

  1. On the files page, describe what you want to design and press Enter, or start from a template.
  2. Draw with the tools in the top bar: Frame (F), Rectangle (R), Text (T), Pen (P).
  3. Select a layer to change its size, colours and layout in the Design panel on the right. Drag layers in the Layers panel on the left to reorder or nest them.
  4. Link screens in the Prototype tab, then press the Present button (Ctrl+Alt+Enter, or ⌘⌥Enter on a Mac) to try the flow.
  5. Open the Code tab for React, HTML or CSS of the selection, or use Export code for a whole project.

Press ? in the editor for every shortcut. Main menu, Help, Show tips again brings the first-run hints back.

Claude setup

Claude can design, critique and fix your file. Open its panel with Ctrl+/ (⌘/ on a Mac). It needs one of two things:

Claude Pro or Max, through Claude Code. No extra cost.

  1. Install Claude Code, run claude once and type /login.
  2. Install the Designotron bridge (macOS or Linux): 
    curl -fsSL https://raw.githubusercontent.com/mikemich/designotron/main/install.sh | sh
    On Windows, download it from the project's Releases page.
  3. The bridge starts in the background. If the installer tells you to start it yourself, run ~/.local/bin/designotron.
  4. The editor connects by itself a few seconds later. The panel says "Bridge connected" when it has.

If the panel says the bridge is running but Claude Code isn't installed, finish step 1 and restart the bridge.

An Anthropic API key. Paste it in the panel. It is kept in this browser only and billed per use.

Each file keeps its own conversation. New conversation (the plus button) keeps the old one under Past conversations, up to 20 per file in this browser.

Sharing

The Share button offers three ways:

  • Online: a live session through a relay server, with cursors and selections.
  • Send a copy: a link that carries the file itself.
  • Local network: a link for people on the same Wi-Fi. It needs the bridge running on your computer.

Links can allow editing or viewing only. Anyone with an editing link can change the file, so share it with people you trust.

Where your files live

Files are stored in this browser (IndexedDB) on this computer. They are not uploaded anywhere unless you share them. Clearing site data for this address deletes them, so keep a copy of anything important: File menu, Save as .dtron downloads a plain JSON file you can open again from the same menu.

The Claude conversations are stored in the same place. Deleting a file deletes its conversations.

Files Claude Code writes (an exported project, for example) go to the bridge's workspace folder, ~/Designotron by default.
