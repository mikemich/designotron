Design notes

Build calmer interfaces

A practical guide to spacing, type and colour

Good typography does most of the work. Start with a clear scale and stick to it across every screen.

Use one accent colour, sparingly, and check contrast with the WCAG guidelines. Code like gap: 16px should look different from prose.

Line length matters: keep paragraphs between 60 and 75 characters so readers can track from line to line without losing their place on the screen.
