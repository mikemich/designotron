# designotron

Free, open-source design tool with Claude built in.

```bash
npx designotron
```

Downloads the Designotron binary for your platform (once), starts the editor at
http://127.0.0.1:5174 and opens it. Sign in to [Claude Code](https://code.claude.com)
(`claude`, then `/login`) to use Claude with your Pro/Max plan.

Source and docs: https://github.com/mikemich/designotron
